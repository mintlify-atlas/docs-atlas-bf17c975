Koharu is a Rust desktop application that automates manga translation using a staged ML pipeline. It runs vision models and LLMs locally, keeping your pages and data on your machine while delivering a complete translation workflow: detect, recognize, inpaint, translate, render, and export.

## What Koharu does

Koharu runs a staged pipeline on each manga page — it doesn't try to solve everything with a single model. Each stage produces well-defined output that the next stage consumes:

<Steps>
  <Step title="Detect">
    Vision models find text blocks, speech bubble regions, and build a per-pixel segmentation mask for cleanup. Font and color hints are also estimated at this stage.
  </Step>
  <Step title="OCR">
    Cropped text regions are passed to OCR models that recognize the source text, including vertical Japanese dialogue and horizontal captions.
  </Step>
  <Step title="Inpaint">
    The segmentation mask guides an inpainting model to erase source lettering from the page, leaving a clean canvas for translated text.
  </Step>
  <Step title="Translate">
    A local GGUF model (via llama.cpp) or a remote provider (OpenAI, Gemini, Claude, DeepSeek) translates the recognized text.
  </Step>
  <Step title="Render and export">
    The text renderer places translated text back onto the cleaned page using OpenType shaping with vertical CJK and RTL support. Export as a flattened image or a layered PSD.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Local-first privacy" icon="lock">
    Vision models and local LLMs run entirely on your machine. When you use a remote provider, only OCR text is sent — never the page image.
  </Card>
  <Card title="GPU acceleration" icon="microchip">
    CUDA (NVIDIA), Metal (Apple Silicon), Vulkan, and ZLUDA (AMD experimental) are supported. CPU fallback is always available.
  </Card>
  <Card title="Headless and API modes" icon="terminal">
    Run without the desktop window for browser-based access, batch jobs, or local automation. The same pipeline powers all modes.
  </Card>
  <Card title="MCP agent integration" icon="plug">
    The built-in MCP server lets AI agents drive the full translation pipeline — open documents, detect, OCR, translate, and export.
  </Card>
  <Card title="PSD export" icon="layer-group">
    Export layered Photoshop files with editable translated text layers for downstream cleanup and manual refinement.
  </Card>
  <Card title="Advanced text rendering" icon="font">
    OpenType shaping with vertical CJK layout, RTL support, font fallback, and manga-oriented stroke compositing.
  </Card>
</CardGroup>

## Supported platforms

Koharu provides prebuilt binaries for Windows, macOS (Apple Silicon and Intel), and Linux. GPU acceleration availability varies by platform:

| Platform | CUDA | Metal | Vulkan | ZLUDA |
|----------|------|-------|--------|-------|
| Windows  | ✓    | —     | ✓      | ✓ (experimental) |
| macOS    | —    | ✓     | —      | — |
| Linux    | ✓    | —     | ✓      | — |

<Note>
  CPU fallback is always available on all platforms when GPU acceleration is unavailable or not worth the setup cost.
</Note>

## Automation and integration

Koharu exposes three ways to integrate with other tools:

- **Local HTTP API** at `http://127.0.0.1:<PORT>/api/v1` — the same API the desktop UI uses
- **MCP server** at `http://127.0.0.1:<PORT>/mcp` — for AI agent workflows
- **Headless mode** with `--headless` — serves the Web UI and API without launching the desktop window

See [Run GUI, Headless, and MCP Modes](/how-to/run-gui-headless-and-mcp) and the [HTTP API Reference](/reference/http-api) to get started.
