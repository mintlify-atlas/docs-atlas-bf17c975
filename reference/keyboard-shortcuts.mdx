Koharu's editor supports a small set of keyboard and pointer shortcuts for navigating the canvas and working with text blocks. These controls apply in the main page editor view.

## Canvas controls

| Shortcut | Action |
|----------|--------|
| `Ctrl` + mouse wheel | Zoom in or out on the canvas |
| `Ctrl` + drag | Pan the canvas |

## Text block controls

| Shortcut | Action |
|----------|--------|
| `Del` | Delete the currently selected text block |

<Note>
  `Ctrl` refers to the Control key on Windows and Linux. On macOS, the same actions use the Command (`⌘`) key where applicable.
</Note>
